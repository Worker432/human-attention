# Продолжение HAT в Google Colab

1. Откройте https://colab.research.google.com/ и выберите «Загрузить блокнот».
2. Выберите `Обучение HAT.ipynb` из этой папки.
3. В настройках среды выполнения выберите GPU. Платный тариф не обязателен для попытки запуска, доступность GPU не гарантирована.
4. Выполняйте ячейки сверху вниз. Подключение Google Drive подтверждает владелец аккаунта.
5. Во второй ячейке загрузите `hat-colab-transfer.zip` из этой же папки. Архив около 290 МБ содержит только код и контрольную точку, без личных записей и статей.
6. Дождитесь подготовки данных и проверки реального шага. Последняя ячейка запускает обучение.

GPU/CUDA здесь ещё не проверены: подготовка локально не является запуском на сервере. При повторном сеансе загрузка исходного архива не заменяет более свежие веса в Drive. Изображения каждый сеанс копируются/распаковываются на локальный диск среды; журналы и веса пишутся в Drive. Нужно несколько ГБ свободного места. Моментальное аварийное отключение может потерять последние несохранённые шаги.

Архив игнорируется Git. Не публикуйте его: он содержит экспериментальные веса. Данные скачиваются с официального источника; условия COCO-FreeView сохраняют силу.
