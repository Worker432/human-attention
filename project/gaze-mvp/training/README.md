# Ограниченная история и подготовка HAT

Новая подсистема не импортирует DeepGaze и не использует его веса. Действующий
прогноз DeepGaze и интерфейс пока не изменены. Полная HAT ещё не интегрирована в приложение,
обученные веса не созданы. Отдельный перенос полного вычислительного пути
прошёл синтетический обучающий замер: [результаты](benchmarks/README.md). Приведённый ниже smoke test проверяет одну операцию,
а не обучение всей модели.

## Выполненная проверка

Оборудование: Apple M4 Pro, 24 GB, Metal/MPS. PyTorch 2.14.1.
MPS доступен при запуске вне ограниченного окружения процесса.
Официальная HAT проверена по версии `557205d3136a63120041c700ee717196a429e89b`:
https://github.com/cvlab-stonybrook/HAT

Штатный `train.py` выбирает CUDA; сборщик `MSDeformableAttn` требует CUDA_HOME.
Окружение авторов рассчитано на Linux, Python 3.9, PyTorch 1.13.1, Detectron2.
Подмена этих зависимостей установкой старого requirements в окружение приложения
не выполнялась. Для Mac нужен отдельный перенос. Полный forward/backward перенесённой версии проверен на синтетических входах;
обучение на реальных данных и сходимость пока не проверены.

`deformable_attention.py` реализует многомасштабную выборку через `grid_sample`
с обычным autograd. Это необходимый компонент переноса, а не замена HAT другой
нейросетью. Проверены аналитический константный пример, численные градиенты
CPU float64 и согласованность с CPU для float32 MPS. Максимальное расхождение
на проверенном входе — 1.64e-7. Скорость этого маленького примера не является
оценкой скорости HAT. Сравнение с CUDA-расширением не выполнено: CUDA отсутствует.

`history.py` хранит только последние K координат в хронологическом порядке.
Отсутствующие точки маскируются; координата заполнителя не является фиксацией.
При K=0 история пуста. Журнал результатов сюда не включается.

## Повторение

Из папки `project/gaze-mvp`:

```bash
.venv-detector/bin/python -m training.audit_freeview \
  ../../dataset/coco-freeview/raw/COCOFreeView_fixations_trainval.json \
  --output ../../dataset/coco-freeview/audit.json
.venv-detector/bin/python -m training.smoke_core --device cpu
.venv-detector/bin/python -m training.smoke_core --device mps
.venv/bin/python -m unittest discover -s tests -q
```

## Следующий этап

1. Проверить визуальное соответствие фотографий полотну предъявления.
2. Перенести ResNet/пиксельный декодер и HAT, явно документируя изменения Detectron2.
3. Проверить полный forward/backward, нормированную пространственную NLL,
   пиковую память и время на реальном входе. Не использовать прогнозы DeepGaze.
4. Подключить окно K=6 без накопленного состояния за пределами окна, затем
   обучение и сравнение K=0,2,4,6,8,12 в одинаковых разбиениях.
5. Только после появления проверенных весов добавить новую модель в UI.

## Видимый полный запуск K=6

Откройте `Обучение HAT.command` в папке приложения. Окно терминала показывает
подготовку и затем обучение. Сначала загружаются официальные TP/TA фотографии
(около 2,2 ГБ); частичная загрузка продолжается при повторном запуске.
После проверки всех изображений и пробного реального шага запускается обучение.
ResNet50 инициализируется ImageNet V2, он заморожен. Пиксельный декодер и
модули истории обучаются на COCO-FreeView без DeepGaze.

Параметры: K=6, seed42, 512×320, batch4, AdamW lr1e-4, пространственная NLL
на сетке 128×80, максимум5 эпох. Проверочная история всегда истинная.
Все цели после первой точки каждой записи входят в проход (535146 train).
Периодически показывается проверка на фиксированных 2048 валидационных целях;
выбор best.pt и ранняя остановка используют полную валидацию в конце эпохи.
После двух эпох без улучшения полной NLL минимум на0,001 обучение останавливается.
Это начальный экспериментальный бюджет, не гарантия сходимости или качества.

Результаты — в игнорируемом `models/hat-freeview-k6-seed42/`:
`console.log`, `metrics.jsonl`, `status.json`, `config.json`, `latest.pt`, `best.pt`.
Latest сохраняется каждые1000 шагов, не реже10 минут, в конце эпохи и при
Ctrl+C. Остановка завершается после текущего шага; повторный запуск продолжает
с сохранённой позиции. Изменение данных, кода, batch или среды блокирует
несовместимое продолжение. Не закрывайте ноутбук: caffeinate предотвращает
обычный сон при открытой крышке, но не гарантирует работу при её закрытии.

Подробности переноса: `hat_port/PROVENANCE.md`. Автономные маршруты, сохранение
вероятностной головы для инференса и интеграция в UI пока требуют отдельной
проверки. Обучение в этой команде не запускает сравнение шести K автоматически.
